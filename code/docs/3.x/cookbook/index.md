# SOC cookbook

Short recipes for everyday security work. Each recipe solves one task in a few lines of TB. Copy a recipe, change the file name, and run it on your own data.

## How the recipes work

Every recipe reads sample files from `apps/data/`, for example `apps/data/auth.log` and `apps/data/sample.pcap`. The playground has these files, so the **Run** buttons work in your browser. The sample data uses documentation addresses, for example `203.0.113.42`, and made-up names.

A few steps need the network or an API key. These steps have a note and no Run button. Run them with the TB app on your computer.

To learn the language step by step, read [the TB book](site:book/index.html). For every function, see the [library reference](site:library.html).
