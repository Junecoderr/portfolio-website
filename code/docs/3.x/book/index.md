# The TB book

This book teaches TB from your first line of code to a working security tool and a desktop app. Read the chapters in order. Each chapter is short and builds on the one before it.

## How to use this book

Most code blocks have a **Run** button. Push it to run the code in your browser. Change the code and run it again. That is the fastest way to learn.

Some blocks need the TB app on your computer, because they open windows, use the network or run work on many threads. These blocks have a note and no Run button. To run them, [download TB](site:download.html), save the code as `file.tb` and type `tb file.tb`.

The examples read sample files from `apps/data/`, for example `apps/data/auth.log`. The playground and the Run buttons have these files. If you run the code on your computer, run it from a copy of the `apps` folder.

## Who this book is for

You do not need to know another programming language. If you already know Python or JavaScript, you can read faster. The chapters about security tools use logs and indicators that a SOC analyst sees every day.

For short tasks, see the [SOC cookbook](site:cookbook/index.html). For every function, see the [library reference](site:library.html).
