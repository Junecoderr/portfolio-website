# Changelog

## 3.1.0

- Released alongside TB 3.1. Signature help highlights the input you are typing, including named inputs (`workers = 8`) for standard-library functions.

## 3.0.0

- First release, alongside TB 3.0.
- Highlighting for the 3.0 syntax (classes, match, f-text format specs, raw/multi-line/bytes text, hex/binary/octal numbers, type annotations).
- Snippets, language configuration, TB: Run File / Format / Check / Run Tests.
- Language server client for `tb lsp` (degrades gracefully when it isn't available).
