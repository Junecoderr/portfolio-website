The Tab key indents. To move on with the keyboard, press Esc first, then Tab. Share copies a link that opens this exact code.

      
This is TB 3.0.0, running on the same bytecode virtual machine as the TB app. All the libraries work here except the ones that need your computer: windows (gui), the network (http, intel, dns, tls, websocket, server, network lookups in net, sending from siem), threads (parallel; async tasks run one after another here) and os.run. The sample data from the tutorials, including a packet capture and a Windows event log, is in apps/data/: try fs.list("apps/data").
