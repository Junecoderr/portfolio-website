What you can build

TB 2.0 grew up. The same gentle language now builds real tools, and every example on this site is a program you can download and run.

Desktop apps

Windows with buttons, tables, menus and dialogs, from a few lines of TB. They run on Windows, macOS and Linux with nothing else installed.

See it in: To-do list, Care check-in, Notes, Calculator

Desktop code: runs with the TB app, not in the browser.

import gui
import hash

let win = gui.window("Hash checker", {"theme": "dark"})
let result = win.label("Pick a file to fingerprint it.")
win.button("Choose file", fn() {
  let path = gui.open_file()
  if path != nil {
    result.set(hash.file_sha256(path))
  }
}, {"primary": true})
win.run()

SOC and detection

Parse auth, web, firewall and Windows logs, describe what bad looks like as a rule (or load a Sigma rule), and get a ranked table of alerts.

See it in: Log triage, Brute-force hunter, Sigma runner, IOC workbench

import logs
import detect
import report

let records = logs.read("apps/data/auth.log", "auth")
let alerts = detect.brute_force(records)
say(report.table(alerts, ["level", "rule", "by", "count", "success_user"]))

Network and intel

Check the ports on machines you own, resolve names, call web APIs, and ask VirusTotal or AbuseIPDB about an indicator.

See it in: Port check, IP reputation, Uptime monitor

Desktop code: runs with the TB app, not in the browser.

import net
import intel

# Only check computers you own or are allowed to test.
let open = net.check_ports("127.0.0.1", [22, 80, 443])
say(open)

if intel.has_key("abuseipdb") {
  let r = intel.abuseipdb("203.0.113.42")
  say(f"{r.verdict} (score {r.score})")
}

Scripts and automation

Read a CSV, reshape it, write JSON. Files, dates, regular expressions and reports are all built in.

import csv
import json

let rows = csv.parse("name,cups\nTanisha,3\nMum,5\nDad,2")
let total = rows.map(fn(r) { return num(r.cups) }).sum()
let top = rows.sort_by(fn(r) { return num(r.cups) }).last()
say(f"{total} cups of tea, most by {top.name}")
say(json.stringify({"total": total, "top": top.name}))

Batteries included

Twenty libraries ship inside the TB app. No package manager, no setup: write import logs and go.

  • mathNumbers beyond + - * /: square roots, powers, rounding, trigonometry.Core
  • textText helpers: padding, wrapping, number formatting and random ids.Core
  • timeClocks and dates: the time now, timestamps, formatting, parsing and waiting.Core
  • randomRandom numbers, picks and shuffles (use seed(n) to repeat them).Core
  • reRegular expressions: search text with patterns like "\d+" (digits) or "\w+@\w+".Core
  • osThe computer TB runs on: your program's arguments, environment variables, running other programs, and exiting.Core
  • fsFiles and folders: read, write, list, walk, copy and remove.Files and data
  • jsonRead and write JSON, the data format of the web and of most security tools.Files and data
  • csvRead and write CSV files.Files and data
  • logsRead log files into records (maps) you can search and count: syslog, Linux auth.log (SSH and sudo), Apache/nginx access logs, JSON lines, CSV and Windows Security event exports.Security (SOC)
  • detectDetection rules for logs: describe what suspicious looks like as a map (or load a Sigma rule), run it over records from the logs library, and get alerts back.Security (SOC)
  • iocIndicators of compromise (IOCs): pull IPs, domains, URLs, emails, file hashes and CVE IDs out of any text, check what something is, and defang them (1.2.3[.]4, hxxp://) so nobody clicks a bad link by accident.Security (SOC)
  • hashHashes (fingerprints) of text and files: MD5, SHA-1, SHA-256 and SHA-512, HMAC signatures, and a safe way to compare secrets.Security (SOC)
  • encodeEncodings attackers (and the web) use: base64, hex, URL encoding and ROT13, plus entropy to spot random-looking text such as packed code or generated domains.Security (SOC)
  • reportTurn records and alerts into something to read or share: aligned text tables, Markdown, CSV, a self-contained HTML page, and a timeline.Security (SOC)
  • netIP addresses, CIDR ranges, DNS lookups and simple TCP checks.Network and intel
  • httpTalk to websites and web APIs: get, post, request and download.Network and intel
  • intelThreat-intelligence lookups for IPs, domains, URLs and file hashes using VirusTotal, AbuseIPDB and URLhaus.Network and intel
  • guiDesktop windows: buttons, text boxes, tables, menus and dialogs.Desktop GUI
  • testChecks for your own tests.Testing

Still gentle

TB began as a gift, a language for someone who had never programmed. 2.0 kept every bit of that.

Friendly errors

Every mistake names the line and says what went wrong, in plain English. Typos get a suggestion.

let name = "Tanisha"
let greeting = "Hello"
say(greeting + ", " + nmae)
Oops! On line 3: I don't know what 'nmae' is. Did you mean 'name'?

A quick tour

Six short programs cover most of the language. Press Run on any of them.

Put any expression inside { } in an f"..." string. Text has methods you call with a dot.

let name = "Tanisha"
let mood = "  sunny  "
say(f"Hello, {name}! Today feels {mood.trim()}.")
say(name.upper(), name.len(), name.contains("tan"))
say("a,b,c".split(","))

Lists keep things in order. Methods like map and filter take a function.

let scores = [7, 10, 4, 9]
say(scores.sort(), scores.sum(), scores.max())
say(scores.filter(fn(s) { return s >= 7 }))
say(scores.map(fn(s) { return s * 10 }))
say(9 in scores)

A map pairs keys with values. Read a field with a dot or with brackets.

let alert = {"ip": "203.0.113.42", "tries": 22}
alert.level = "critical"
alert["tries"] += 1
say(alert)
for key in alert {
  say(f"{key} = {alert[key]}")
}

for walks through a list, text or map. break stops early, continue skips ahead.

for n in range(1, 20) {
  if n % 2 == 0 {
    continue
  }
  if n > 9 {
    break
  }
  say(f"{n} is odd")
}

Every mistake can be caught. The error is a map with a message and a line number.

import json

try {
  json.parse("{not json")
} catch err {
  say(f"Couldn't read it: {err.message}")
}

fn check(age) {
  if age < 0 { throw "Age can't be negative" }
  return age
}
try { check(-1) } catch err { say(err.message) }

Twenty libraries come built in. import one and use it with a dot.

import hash
import encode
import text

say(hash.sha256("hello").slice(0, 16))
say(encode.base64("TB loves you"))
say(text.format_number(1234567.5, 1))

Why TB?

TB was made as a gift, for one person. Its name is her initials.

It started small and gentle, so learning it would never feel like being told off. Version 2.0 lets it do real work, from a to-do list to triaging an attack, without losing that voice. If you are not Tanisha, you are still very welcome here.

Dear Tanisha,

I made you something a little unusual. It isn't flowers and it isn't a card. It's a whole language, small enough to fit in your pocket, and it carries your initials.

I know code can look like a wall of strange symbols. TB is my attempt to make it feel more like writing a note: you say something, and the computer says something kind back. You can't break anything, and every mistake comes with a gentle hint.

There's no rush to learn any of it. Open it on a quiet evening, run the first program, and know that every line was written thinking of you.

With love, always.
