import logs

class Suspect {
  fn init(ip) { self.ip = ip; self.tries = 0 }
  fn text() { return f"{self.ip} ({self.tries} failed logins)" }
}

fn failures(records) {
  for r in records {
    if r.action == "failed_login" { yield r.ip }
  }
}

let seen = {}
for ip in failures(logs.read("apps/data/auth.log", "auth")) {
  if ip not in seen { seen[ip] = Suspect(ip) }
  seen[ip].tries += 1
}
for s in seen.values() {
  say(match s.tries {
    0..5 => f"note   {s}"
    5..20 => f"watch  {s}"
    _ => f"block  {s}"
  })
}
import logs
import detect

let records = logs.read("apps/data/auth.log", "auth")

for hit in detect.brute_force(records) {
  say(f"{hit.level}: {hit.count} failed logins from {hit.by}")
  if hit.success_after {
    say(f"  then logged in as {hit.success_user}")
  }
}

What you can build

The same gentle language builds real tools, and every example on this site is a program you can download and run.

Desktop apps

Windows with buttons, tables, menus and dialogs, from a few lines of TB. They run on Windows, macOS and Linux with nothing else installed.

See it in: To-do list, Care check-in, Notes, Calculator

Desktop code: runs with the TB app, not in the browser.

import gui
import hash

let win = gui.window("Hash checker", {"theme": "dark"})
let result = win.label("Pick a file to fingerprint it.")
win.button("Choose file", fn() {
  let path = gui.open_file()
  if path != nil {
    result.set(hash.file_sha256(path))
  }
}, {"primary": true})
win.run()

SOC and detection

Parse auth, web, firewall and Windows logs, describe what bad looks like as a rule (or load a Sigma rule), and get a ranked table of alerts.

See it in: Log triage, Brute-force hunter, Sigma runner, IOC workbench

import logs
import detect
import report

let records = logs.read("apps/data/auth.log", "auth")
let alerts = detect.brute_force(records)
say(report.table(alerts, ["level", "rule", "by", "count", "success_user"]))

Network and intel

Check the ports on machines you own, resolve names, call web APIs, and ask VirusTotal or AbuseIPDB about an indicator.

See it in: Port check, IP reputation, Uptime monitor

Desktop code: runs with the TB app, not in the browser.

import net
import intel

# Only check computers you own or are allowed to test.
let open = net.check_ports("127.0.0.1", [22, 80, 443])
say(open)

if intel.has_key("abuseipdb") {
  let r = intel.abuseipdb("203.0.113.42")
  say(f"{r.verdict} (score {r.score})")
}

Scripts and automation

Read a CSV, reshape it, write JSON. Files, dates, regular expressions and reports are all built in.

import csv
import json

let rows = csv.parse("day,cups\nMon,3\nTue,5\nWed,2")
let total = rows.map(fn(r) { return num(r.cups) }).sum()
let top = rows.sort_by(fn(r) { return num(r.cups) }).last()
say(f"{total} cups of tea, most on {top.day}")
say(json.stringify({"total": total, "top": top.day}))

New in TB 3.0

The language grew the features you reach for in bigger programs, and kept its plain words and friendly errors. Every 2.x program still runs. See everything that's new.

Classes and enums

Describe your own kinds of things with fields, methods and inheritance.

enum Level { low, high }

class Alert {
  fn init(rule, level) {
    self.rule = rule
    self.level = level
  }
  fn text() { return f"[{self.level.name}] {self.rule}" }
}

say(Alert("ssh brute force", Level.high))

Pattern matching

match picks the first pattern that fits: values, ranges, lists, maps, types and classes.

fn triage(event) {
  return match event {
    {"tries": n} if n > 10 => "block the IP"
    {"port": 22 or 3389} => "check remote access"
    [first, ...rest] => f"{len(rest) + 1} events"
    _ => "log it"
  }
}
say(triage({"ip": "203.0.113.42", "tries": 22}))
say(triage({"port": 3389}))

Generators

yield hands out values one at a time, so a pipeline only does the work you ask for.

fn evens() {
  let n = 0
  while true {
    yield n
    n += 2
  }
}
say(evens().map(n => n * n).take(5).to_list())

Tasks with async and await

Start slow work at the same time and collect the answers; parallel spreads it over threads.

async fn check(host) {
  return f"{host}: ok"
}

let tasks = ["web01", "web02", "db01"].map(check)
for t in tasks {
  say(await t)
}

Also new: destructuring and spread, default and named arguments, lambdas, const, bytes, ranges and slices, number formats in f-strings, typed errors with finally, defer and assert, modules with export, and packages. Each has a lesson in the guide.

Batteries included

43 libraries ship inside the TB app, from text and dates to packet captures, Windows event logs, executables, Sigma rules and a web server. Write import pcap and go.

  • datetimeDates and times that know their time zone.Core
  • decimalExact decimal numbers: decimal.of("0.1").add("0.2") is exactly 0.3, where plain numbers give 0.30000000000000004.Core
  • randomRandom numbers, picks and shuffles (use seed(n) to repeat them).Core
  • reRegular expressions: search text with patterns like "\d+" (digits) or "\w+@\w+".Core

  • binaryWork with bytes: make them from hex or lists, pack and unpack numbers the way file formats and network protocols store them (like Python's struct), read little- and big-endian numbers at an offset, show a hex dump, measure entropy, and sniff what kind of file something is.Core
  • fsFiles and folders: read, write, list, walk, copy and remove.Files and data
  • jsonRead and write JSON, the data format of the web and of most security tools.Files and data
  • csvRead and write CSV files.Files and data
  • yamlRead and write YAML, the human-friendly data format Sigma rules, CI pipelines and many configs use.Files and data
  • tomlRead and write TOML, the config-file format used by tb.toml and pyproject.toml: toml.parse(text) gives a map (tables become maps, dates become ISO text), toml.stringify(map) writes one back, toml.read/write work on files.Files and data
  • xmlRead and write XML.Files and data
  • sqliteA real database in a single file (or in memory) using SQLite, which is built into Python.Files and data
  • archiveMake and open .zip, .tar(.gz) and .gz files.Files and data
  • templateFill in text templates.Files and data
  • logsRead log files into records (maps) you can search and count: syslog, Linux auth.log (SSH and sudo), Apache/nginx access logs, JSON lines, CSV and Windows Security event exports.Security operations
  • detectDetection rules for logs: describe what suspicious looks like as a map (or load a Sigma rule), run it over records from the logs library, and get alerts back.Security operations
  • iocIndicators of compromise (IOCs): pull IPs, domains, URLs, emails, file hashes and CVE IDs out of any text, check what something is, and defang them (1.2.3[.]4, hxxp://) so nobody clicks a bad link by accident.Security operations
  • hashHashes (fingerprints) of text and files: MD5, SHA-1, SHA-256 and SHA-512, HMAC signatures, and a safe way to compare secrets.Security operations
  • encodeEncodings attackers (and the web) use: base64, hex, URL encoding and ROT13, plus entropy to spot random-looking text such as packed code or generated domains.Security operations
  • cryptoEncryption and the building blocks around it: AES-GCM and AES-CBC (pure Python, so fine for secrets and small files, slow for gigabytes), random keys, PBKDF2 and scrypt key derivation, HMAC, TOTP one-time codes, JWTs (sign HS256/384/512, verify HS* and RS*), scrypt password hashing, RSA signature checks and X.509 certificate parsing.Security operations
  • reportTurn records and alerts into something to read or share: aligned text tables, Markdown, CSV, a self-contained HTML page, and a timeline.Security operations
  • pcapRead network captures (pcap and pcapng) into packet maps: Ethernet and VLAN, IPv4/IPv6, ARP, TCP, UDP and ICMP, with DNS questions and answers, HTTP requests, and the server name (SNI) from TLS hellos.Security operations
  • evtxRead binary Windows event logs (.evtx, the files in C:\Windows\System32\winevt\Logs) straight from the file, with no Windows needed.Security operations
  • peRead Windows executables (PE: .exe, .dll, .sys) without running them: architecture, compile time, entry point, sections with their entropy and permissions, imports and exports, whether the file is signed, and a list of suspicious indicators (packer section names, writable+executable sections, injection or keylogging imports, odd entry points).Security operations
  • elfRead Linux/Unix executables and shared libraries (ELF) without running them: architecture, type, entry point, sections and segments with entropy and permissions, the libraries it needs, imported and exported symbols, the program interpreter, and suspicious indicators (writable+executable memory, UPX section names, ptrace/dlopen imports, odd interpreters).Security operations

  • attackMITRE ATT&CK Enterprise at your fingertips: look up a technique by id (attack.technique("T1110")), search by words, list a tactic's techniques, and map detect alerts to techniques through their Sigma tags (attack.t1110.001).Security operations

Tools that come with it

Everything a bigger project needs is one tb command away, and the VS Code extension puts it in your editor.

Format, check, test

tb fmt lays code out the same way every time, tb check finds mistakes before you run (with optional type hints), and tb test --coverage runs your tests and shows which lines they reached.

> tb fmt --check .
> tb check main.tb
> tb test --coverage

Debug and build

tb debug steps through a program with breakpoints and shows every variable; tb build packs an app into a folder you can hand to someone without TB.

> tb debug main.tb
> tb build apps/todo/main.tb

Packages

tb init starts a project, tb add installs a package and pins it in tb.lock. Browse the packages.

> tb init
> tb add tb-tables

VS Code extension

Highlighting, completion, hover help, errors as you type, go to definition, formatting and Run buttons, from tb lsp. Install it from the download.

Still gentle

TB is designed for people who have never programmed, and it stays that way when the programs get bigger.

Friendly errors

Every mistake names the line and says what went wrong, in plain English. Typos get a suggestion.

let name = "Tanisha"
let greeting = "Hello"
say(greeting + ", " + nmae)
Oops! On line 3: I don't know what 'nmae' is. Did you mean 'name'?

A quick tour

Nine short programs cover most of the language. Press Run on any of them.

Put any expression inside { } in an f"..." string. Text has methods you call with a dot.

let name = "Tanisha"
let mood = "  sunny  "
say(f"Hello, {name}! Today feels {mood.trim()}.")
say(name.upper(), name.len(), name.contains("le"))
say("a,b,c".split(","))

Lists keep things in order. Methods like map and filter take a function.

let scores = [7, 10, 4, 9]
say(scores.sort(), scores.sum(), scores.max())
say(scores.filter(fn(s) { return s >= 7 }))
say(scores.map(fn(s) { return s * 10 }))
say(9 in scores)

A map pairs keys with values. Read a field with a dot or with brackets.

let alert = {"ip": "203.0.113.42", "tries": 22}
alert.level = "critical"
alert["tries"] += 1
say(alert)
for key in alert {
  say(f"{key} = {alert[key]}")
}

for walks through a list, text or map. break stops early, continue skips ahead.

for n in range(1, 20) {
  if n % 2 == 0 {
    continue
  }
  if n > 9 {
    break
  }
  say(f"{n} is odd")
}

Every mistake can be caught. The error has a message, a line number and a kind, so you can catch just the kinds you expect.

import json

try {
  json.parse("{not json")
} catch err: ParseError {
  say(f"Couldn't read it: {err.message}")
} finally {
  say("done")
}

fn check(age) {
  if age < 0 { throw "Age can't be negative" }
  return age
}
try { check(-1) } catch err { say(err.message) }

Dozens of libraries come built in. import one and use it with a dot.

import hash
import encode
import text

say(hash.sha256("hello").slice(0, 16))
say(encode.base64("Hello from TB"))
say(text.format_number(1234567.5, 1))

A class bundles data and the things you can do with it. extends builds on another class, and super reaches the parent's version.

class Host {
  fn init(name, ip) {
    self.name = name
    self.ip = ip
  }
  fn text() { return f"{self.name} ({self.ip})" }
}

class Server extends Host {
  fn init(name, ip, ports = [22]) {
    super.init(name, ip)
    self.ports = ports
  }
}

let web = Server("web01", "192.0.2.10", [80, 443])
say(web, web.ports, web is Host)

match tries patterns in order. Lists and maps can be taken apart into names, here and in let.

let events = [
  {"kind": "login", "user": "Tanisha"},
  {"kind": "scan", "ports": [22, 80, 443]},
  {"kind": "alert", "level": 9},
]
for e in events {
  say(match e {
    {"kind": "login", "user": who} => f"{who} logged in"
    {"ports": [first, ...rest]} => f"scan from port {first}, {len(rest)} more"
    {"level": n} if n > 7 => "urgent alert"
    _ => "other"
  })
}
let {kind, user = "nobody"} = events[1]
say(kind, user)

A function with yield makes values one at a time. Chain map, filter and take and only the values you need are made.

fn fibonacci() {
  let [a, b] = [0, 1]
  while true {
    yield a
    a, b = b, a + b
  }
}
say(fibonacci().take(10).to_list())
say(fibonacci().filter(n => n % 2 == 0).take(5).to_list())
for i, n in fibonacci().take(3).enumerate() {
  say(f"#{i}: {n}")
}

Why TB?

TB is a small language with a few firm design goals.

It starts gentle, so learning it never feels like being told off, and it grows into real work: a to-do app, a log triage tool or a quick script.

  • Friendly errors

    Every mistake names the line and says what went wrong in plain English, with a suggestion when it looks like a typo.

  • Batteries included

    43 libraries ship with the language: windows and buttons, files and data formats, logs, detection rules, hashing, crypto and networking. Packages add more when you need them.

  • Runs everywhere

    The same program runs on Windows, macOS and Linux, and in the browser playground.

  • Small and readable

    Plain words like say, let and for, and a syntax small enough to learn in an afternoon.
