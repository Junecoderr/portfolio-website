Why your computer might warn you

When you open TB for the first time, Windows or macOS may show a warning saying it doesn't recognise the app. That's expected, and here is the honest reason.

Big companies pay every year for a code-signing certificate, a kind of ID card that tells your computer who made a program. TB is a small gift, not a company product, so it doesn't have one. Your computer simply hasn't met TB before, so it plays safe and asks you first.

TB can't reach the internet, and it only reads the program file you give it. All of its code is public, and you can check that your download is exactly the published file using the checksums below. The steps that follow show how to say "yes, I trust this one".

  1. Download TB and keep it

    Click the Download button above. Because TB is new, your browser might pause and say the file "isn't commonly downloaded".

    In Microsoft Edge: point at the download, click the … (three dots), choose Keep, then Show more and Keep anyway.

    In Chrome: open the downloads list and click Keep.

  2. Make a TB folder

    Open File Explorer, go to Documents, and make a new folder called TB (right-click → New → Folder).

    Move the downloaded file from Downloads into it, and rename it to tb (right-click → Rename). If you see .exe on the end, keep it: the name becomes tb.exe.

    Then download your first program, for_tanisha.tb, and move it into the same folder.

  3. Drag the program onto TB

    This is the easiest way to run a TB program. Click and hold for_tanisha.tb, drag it on top of tb.exe, and let go.

Writing your own program

  1. Open Notepad and type say("Hello from me!")

  2. Choose File → Save as. Go to your TB folder. Set Save as type to All files and name it hello.tb.

    If you leave the type as "Text documents", Notepad quietly names it hello.tb.txt, and TB won't recognise it.

  3. Drag hello.tb onto tb.exe, just like before.

The terminal way (optional)

Open your TB folder in File Explorer. Click the address bar at the top, type cmd and press Enter. A command window opens in that folder. Type:

tb for_tanisha.tb

and press Enter. Typing just tb on its own opens TB's interactive prompt, where you can try one line at a time. Type exit to leave.

Mac

  1. Download and unzip

    Download tb-macos-arm64.zip. Safari usually unzips it for you; if not, double-click the zip in Downloads. You get a file called tb.

    This version is for Macs with Apple silicon (M1 or newer). On an older Intel Mac, use the Python version instead.

  2. Make a TB folder

    In Finder, make a folder called TB inside Documents. Move tb and for_tanisha.tb into it.

  3. Tell macOS you trust TB

    Hold Control and click tb, then choose Open. If the box offers an Open button, click it. That's all.

    On newer macOS versions the box only says Done. Click Done, then open System Settings → Privacy & Security, scroll down to the message about tb, and click Open Anyway. Your Mac asks for your password to confirm.

    Privacy & Security

  4. Run your first program

    Open Terminal (press ⌘ Space, type "Terminal", press Return). Type cd with a space after it, drag your TB folder into the window, and press Return. Then type:

    ./tb for_tanisha.tb

    The first run can take several seconds while macOS checks the new app and TB unpacks itself. Give it a moment; later runs start faster.

    Terminal
    TB % ./tb for_tanisha.tb Hello, Tanisha! This language is called TB. Can you guess why? …
Advanced: remove the warning from Terminal

If you're comfortable in Terminal, this removes the "downloaded from the internet" flag from tb, which has the same effect as Open Anyway:

xattr -d com.apple.quarantine tb

Linux

  1. Download and unpack

    Download tb-linux-x64.tar.gz, open a terminal in the folder where it landed, and unpack it:

    tar -xzf tb-linux-x64.tar.gz

  2. Allow it to run

    Mark the file as a program you're allowed to run:

    chmod +x tb

  3. Run your first program

    Put for_tanisha.tb in the same folder, then:

    ./tb for_tanisha.tb

    To use tb from anywhere, move it into ~/.local/bin.

The Python version

If the app won't run on your computer, tb-python.zip is a fallback. It holds TB itself as a single Python file, tb.py, along with the example programs. It needs Python 3.10 or newer.

Unzip it, open a terminal in that folder, and run:

python tb.py for_tanisha.tb

On Windows, if python isn't found, try py tb.py for_tanisha.tb. On a Mac, use python3.

Check your download (optional)

SHA256SUMS.txt lists a fingerprint (a long code of letters and numbers) for every file. If your file's fingerprint matches its line, it's exactly the file that was published, with nothing changed on the way.

Open a terminal in your Downloads folder and run the command for your computer:

ComputerCommand
Windowscertutil -hashfile tb-windows-x64.exe SHA256
Macshasum -a 256 tb-macos-arm64.zip
Linuxsha256sum -c SHA256SUMS.txt --ignore-missing

Compare the code it prints with the matching line in SHA256SUMS.txt. Capital or small letters don't matter. On Linux the command checks for you and prints OK.

On a Mac, Safari often unzips the download and then moves the zip to the Bin, so there may be nothing left to check. If you want to check it, find the zip in the Bin and put it back (or turn off Open "safe" files after downloading in Safari's settings and download again). Checking is optional: the steps above work either way.
