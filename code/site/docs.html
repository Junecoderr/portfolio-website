Learn TB

A program is just a list of instructions for the computer, written down one after another. TB is a small, friendly language for writing those instructions. You don't need to know anything about programming to start. Go one lesson at a time, and press Run under any code box to see it work.

You can change the code in the Playground as much as you like. Nothing you type can break your computer, and if something goes wrong TB just says "Oops!" and explains what it didn't understand.

1.Your first program: say

say shows something on the screen. Put what you want to show inside the round brackets, and put words inside quote marks "like this" so TB knows they are text.

say("Hello, world!")
say("This is my first program.")

TB reads your program from top to bottom, one line at a time. Each line here is one instruction.

You can give say several things at once, separated by commas. It puts a space between them. say("") with nothing in the quotes prints an empty line, which is nice for spacing things out.

say("I have", 2, "cats")
say("")
say("The end!")

Lines that start with # are comments: little notes for people. TB skips them completely.

# This line is a note. TB ignores it.
say("Only this line does something.")

2.Values: numbers, text, true and false

Everything a program works with is a value. TB has a few kinds:

  • Numbers, like 7, -3 or 2.5.
  • Text, inside double or single quotes: "hello" or 'hello'.
  • true and false, for yes and no.
  • nil, which means "nothing here".
  • Lists of other values, like [1, 2, 3] (more in lesson 5).
say(42)
say("forty-two")
say(true)
say(nil)
say([1, 2, 3])

To put a quote mark inside text, put a backslash in front of it: \". \n starts a new line inside the text.

say("She said \"hi\" to me.")
say("line one\nline two")

3.Remembering things with let

let gives a value a name, so you can use it again later. Think of it as a labelled box.

let name = "Tanisha"
let age = 25
say(name)
say(age)

To change what's in the box later, use the name and = without let. (let is only for making a new box.)

let mood = "sleepy"
say("This morning I felt " + mood)
mood = "happy"
say("After coffee I felt " + mood)

Names can use letters, numbers and _, but can't start with a number: favourite_food, day2. Capital letters matter: Name and name are different boxes.

4.Maths and joining text

TB can do sums. * means times and / means divide. % gives the remainder after dividing (so 7 % 2 is 1). Brackets work like in school maths.

say(2 + 3)
say(10 - 4)
say(6 * 7)
say(7 / 2)
say(7 % 2)
say((2 + 3) * 4)

+ also joins text together. If either side is text, TB joins them as text.

let first = "Tanisha"
let last = "the analyst"
say(first + " " + last)
say("I have " + 3 + " plants")

Text times a number repeats the text:

say("ha" * 3)
say("* " * 5)

Two helpers turn things into other things:

  • str(x) turns anything into text: str(5) is "5".
  • num(text) turns text like "12" into the number 12, so you can do maths with it.
let cups = num("2") + 1
say("Cups of tea today: " + str(cups))

5.Lists

A list keeps several values in order, inside square brackets, separated by commas.

let snacks = ["chocolate", "mango", "chips"]
say(snacks)
say(len(snacks))

len tells you how many things are in a list (or how many letters are in some text).

To get one thing out, put its position in square brackets. Careful: positions start at 0, so the first thing is at position 0, the second at 1, and so on. A negative position counts from the end.

let snacks = ["chocolate", "mango", "chips"]
say(snacks[0])
say(snacks[1])
say(snacks[-1])

You can swap one thing for another, and add new things to the end with push:

let snacks = ["chocolate", "mango", "chips"]
snacks[2] = "popcorn"
push(snacks, "ice cream")
say(snacks)

Two lists can be joined with +: [1, 2] + [3] is [1, 2, 3].

6.Making choices with if and else

if runs some lines only when something is true. The lines that belong to it go inside curly brackets { }. else says what to do otherwise.

let hour = 22
if hour >= 22 {
  say("Time for bed. Sleep well!")
} else {
  say("Still time to play.")
}

You can check several things in a row with else if. TB uses the first one that is true.

let cups_of_water = 3
if cups_of_water >= 8 {
  say("Amazing, so hydrated!")
} else if cups_of_water >= 4 {
  say("Good going, keep sipping.")
} else {
  say("Maybe have a glass of water now?")
}

Ways to compare things:

  • == is the same as (two equals signs, because one = is for putting things in boxes)
  • != is not the same as
  • < less than, > more than, <= less than or the same, >= more than or the same

Join checks together with and and or, and flip one with not.

let sunny = true
let weekend = false
if sunny and not weekend {
  say("Sunny, but it's a work day.")
}
if sunny or weekend {
  say("Something nice is happening!")
}

In TB only false and nil count as "no". Everything else, even 0 and empty text "", counts as "yes".

7.Doing things again and again: loops

while keeps repeating its lines as long as something is true. Make sure something changes each time, or it will go on forever!

let n = 3
while n > 0 {
  say(str(n) + "...")
  n = n - 1
}
say("Surprise!")

for goes through a list one thing at a time. Each time round, the name you choose (here flower) holds the next thing.

let flowers = ["rose", "tulip", "sunflower"]
for flower in flowers {
  say("I picked a " + flower)
}

range makes a list of numbers to count with. range(5) is [0, 1, 2, 3, 4] (it stops just before 5). range(1, 4) is [1, 2, 3]. A third number sets the step: range(10, 0, -5) is [10, 5].

for i in range(1, 4) {
  say("Step number " + str(i))
}

for also works on text, one letter at a time:

for letter in "TB" {
  say(letter)
}

8.Making your own instructions: functions

A function is a little recipe with a name. You write it once with fn, then use it as many times as you like. The names in the round brackets are its inputs.

fn greet(name) {
  say("Hello, " + name + "! Have a nice day.")
}

greet("Tanisha")
greet("world")

return hands a value back, so you can use the answer somewhere else.

fn double(x) {
  return x * 2
}

say(double(4))
say(double(double(4)))

Write a function above the place where you use it, because TB reads from top to bottom. A function with no return gives back nil.

9.Functions that remember (and call themselves)

A function can be a value too: fn(x) { ... } without a name makes one, and you can keep it in a box with let.

let shout = fn(text) {
  return text + "!!!"
}
say(shout("Hello there"))

Here is something magical: a function made inside another function remembers the boxes around it, even after the outer function has finished. This is called a closure. Each counter below has its very own memory.

fn make_counter() {
  let count = 0
  return fn() {
    count = count + 1
    return count
  }
}

let steps = make_counter()
steps()
steps()
say("Steps so far: " + str(steps()))

A function can also call itself, with a smaller problem each time. This is called recursion. Just make sure there's a point where it stops!

fn stars(n) {
  if n <= 0 {
    return ""
  }
  return "* " + stars(n - 1)
}
say(stars(4))

10.Talking to your program: ask and care

ask shows a question and waits for you to type an answer and press Enter. The answer comes back as text. (In the browser, the question pops up in a little box.)

let name = ask("What's your name? ")
say("Nice to meet you, " + name + "!")

The answer is always text, so if you want to do maths with it, turn it into a number with num:

let cups = num(ask("How many cups of tea today? "))
say("Only " + str(cups + 1) + " more and you'll be a professional.")

care is TB's special instruction. It prints a kind message, picked at random, after a ♥ symbol. Give it a name to make the message personal.

care()
care("Tanisha")

Try the Care bot example to see ask and care working together.

11.Reading "Oops!" messages

Everyone who writes programs makes little mistakes all the time. It's completely normal! When TB can't understand something, it stops and tells you which line to look at and what confused it:

Oops! On line 2: I don't know what 'nmae' is. Did you mean 'name'?

Try running this one. It has a typo on line 2:

let name = "Tanisha"
say(nmae)

Some common "Oops!" messages and what they mean:

  • I don't know what 'x' is. You used a name that hasn't been made yet, or there's a spelling mistake. Check the spelling, or add a let.
  • 'x' doesn't exist yet. Use 'let x = ...' first. You tried to change a box before making it. Use let the first time.
  • This text never ends. Did you forget a closing "? A quote mark is missing.
  • ... was never closed. Did you forget a ')'? (or a }) Every opening bracket needs a closing one.
  • Position 3 is outside the list. Remember positions start at 0, so a list of 3 things has positions 0, 1 and 2.
  • I can only subtract numbers ... You tried to do maths with text. Use num() to turn the text into a number first.
# This one has a mistake too. Can you fix it?
let snacks = ["cake", "chips", "mango"]
say(snacks[3])

Tip: the line number is your best friend. Go to that line, read it slowly, and look for a missing quote, bracket or spelling mistake. Sometimes the real mistake is on the line just above.

12.Maps: things with names

A list keeps things in order. A map keeps things by name: each key points to a value. Write it with curly brackets, a colon between each key and its value.

let me = {"name": "Tanisha", "city": "Lisbon", "plants": 4}
say(me["name"])
say(me.city)
say(len(me), "keys")

Read a value with me["name"] or, when the key is a simple word, with a dot: me.name. Set one the same way. Asking for a key that isn't there is a mistake, so use .get(key, default) when you're not sure.

let tea = {"cups": 2}
tea.cups = tea.cups + 1
tea["sugar"] = false
say(tea)
say(tea.get("milk", "no milk"))
for key in tea {
  say(key + " is " + str(tea[key]))
}

Maps are everywhere in TB: a log line, an alert and a JSON file all come back as maps.

13.Methods: asking a value to do something

Text, lists, maps and numbers come with methods: little built-in functions you call with a dot after the value. "hi".upper() asks the text "hi" for its capital-letter version.

let name = "  Tanisha  "
say(name.trim().upper())
say("apple,mango,kiwi".split(","))
say("Hello".contains("ell"), "Hello".starts_with("He"))
say("ha".repeat(3))

Lists have the most useful ones. map, filter and sort_by take a function and use it on every item.

let cups = [3, 1, 4, 1, 5]
say(cups.sum(), cups.max(), cups.sort())
say(cups.filter(fn(c) { return c > 2 }))
say(cups.map(fn(c) { return c * 2 }))
say(["b", "a", "c"].sort().join(" < "))

See every method in the library reference.

14.Text with holes: f-strings

Joining text with + gets fiddly. Put an f before the quotes and you can drop any value straight into the text inside { }. TB fills in each hole when the line runs.

let name = "Tanisha"
let cups = 3
say(f"{name} has had {cups} cups of tea.")
say(f"That's {cups * 250} ml, or {round(cups * 0.25, 2)} litres.")
say(f"Shouting: {name.upper()}!")

Plain "..." text never fills in holes, so curly brackets in ordinary text stay as they are. To put a real curly bracket in an f-string, write it twice: {{ or }}.

15.Libraries: import

TB comes with 43 libraries, extra sets of instructions for jobs like reading files, working with dates, parsing logs or opening windows. Bring one in with import, then use its functions with a dot.

import math
import text

say(math.sqrt(81))
say(text.pad_left("7", 3, "0"))
say(math.round(math.pi, 2))

You can give a library a shorter name with as, and you can import your own .tb files too: import "helpers.tb" gives you everything that file made with let and fn.

import encode as enc
say(enc.base64("secret message"))

The library reference lists every library and function. In the browser, the libraries that need your computer (windows, the network) explain that politely instead of running.

16.Catching mistakes: try, catch and throw

Some mistakes aren't in your program but in the world: a file that isn't there, text that isn't a number. Put the risky lines inside try, and say what to do instead in catch. The error arrives as a map with a message and a line.

try {
  let n = num("twelve")
  say(n)
} catch err {
  say(f"That didn't work: {err.message}")
}
say("...and the program carries on.")

throw raises your own error, with text or a map. Whoever called your function can catch it.

fn take(cups) {
  if cups > 10 {
    throw {"message": "That's too much tea", "cups": cups}
  }
  return cups
}

try {
  take(12)
} catch err {
  say(err.message, "(" + str(err.cups) + " cups)")
}

An error nobody catches stops the program with the usual friendly "Oops!", like this one:

throw "Something went wrong"

17.More loops: break, continue, in and +=

break leaves a loop straight away. continue skips to the next time round.

for n in range(1, 100) {
  if n % 3 != 0 {
    continue
  }
  if n > 15 {
    break
  }
  say(n)
}

in asks whether something is inside a list, text or map, and not in asks the opposite. += adds to a box in one step (-=, *= and /= work too).

let seen = []
let total = 0
for word in ["tea", "cake", "tea", "rain"] {
  if word not in seen {
    seen.push(word)
  }
  total += 1
}
say(seen, total)
say("cake" in seen, "x" in "TB")

Lessons 1 to 17 cover everything you need to write useful programs. The next lessons are about the parts that arrived in TB 3.0: your own classes, pattern matching, generators, tasks and more. Programs written for TB 2 keep working; What's new in 3.0 has the full list and Moving from 2.x the few things that changed.

18.Your own kinds of things: classes

A class describes a kind of thing: what it remembers (its fields) and what it can do (its methods). Calling the class makes a new instance. Inside a method, self is the instance it was called on.

class Alert {
  let level = "low"
  static let count = 0

  fn init(rule, ip) {
    self.rule = rule
    self.ip = ip
    Alert.count += 1
  }

  fn text() {
    return f"[{self.level}] {self.rule} from {self.ip}"
  }
}

let a = Alert("ssh brute force", "203.0.113.42")
say(a)
a.level = "high"
say(a.rule, a.level)
say(type(a), Alert.count)

init runs when an instance is made. let inside the class gives every instance a field with a starting value; static let belongs to the class itself. A method called text() decides how the instance looks in say and f-strings.

A class can extend another and get all of its fields and methods. super.method() calls the parent's version; x is ClassName checks what something is.

class Animal {
  let sound = "..."
  fn init(name) { self.name = name }
  fn speak() { return f"{self.name} says {self.sound}" }
}

class Dog extends Animal {
  let sound = "woof"
  fn init(name) {
    super.init(name)
    self.tricks = []
  }
  fn speak() { return super.speak() + "!" }
}

let d = Dog("Rex")
d.tricks.push("sit")
say(d.speak())
say(d is Animal, d is Dog, type(d))
say(d.fields())

19.A fixed set of choices: enum

An enum names a small, fixed set of values, so you can't mistype one. Each value knows its .name and its position, .index.

enum Level { low, medium, high }

let now = Level.medium
say(now, now.name, now.index)
say(now == Level.medium, now == Level.high)
for level in Level.values() {
  say(level.index, level.name)
}

20.Choosing by shape: match

match compares a value against a list of patterns, top to bottom, and gives the result of the first arm that fits. _ fits everything, so it goes last.

fn describe(x) {
  return match x {
    0 => "zero"
    1..=9 => "a small number"
    n if n is number and n < 0 => "below zero"
    "critical" or "high" => "act now"
    is text => f"some text: {x}"
    [] => "an empty list"
    [first, ...rest] => f"a list starting with {first} ({len(rest)} more)"
    {"ip": ip, "port": 22} => f"SSH on {ip}"
    _ => "something else"
  }
}

for x in [0, 7, -3, "high", "hello", [], [5, 6, 7], {"ip": "192.0.2.10", "port": 22}, nil] {
  say(describe(x))
}

Patterns can be plain values, several values joined with or, ranges like 1..=9, a name that catches the value (with an if guard), is text, lists with ...rest, and maps that need certain keys. They also work with enums and classes:

enum Level { low, medium, high }

class Alert {
  fn init(rule, level) {
    self.rule = rule
    self.level = level
  }
}

let alerts = [Alert("port scan", Level.medium), Alert("new admin", Level.high), Alert("login", Level.low)]
for a in alerts {
  let action = match a.level {
    Level.high => "page someone"
    Level.medium => "open a ticket"
    _ => "just log it"
  }
  say(f"{a.rule}: {action}")
}

let first = alerts[0]
match first {
  Alert {rule: r, level: Level.medium} => say(f"medium alert: {r}")
  _ => say("something else")
}

If nothing fits and there is no _ arm, TB stops with an Oops that shows the value, so you notice the case you forgot.

21.Unpacking and spreading

Destructuring takes a list or map apart into named pieces in one step. In a map pattern, ip: address renames a key and owner = "nobody" gives a default when the key is missing. Spread (...) does the opposite and pours a list or map into a new one.

let ports = [22, 80, 443, 8080]
let [first, second, ...rest] = ports
say(first, second, rest)

let host = {"name": "web01", "ip": "192.0.2.10"}
let {name, ip: address, owner = "nobody"} = host
say(name, address, owner)

for [port, service] in [[22, "ssh"], [443, "https"]] {
  say(f"{port} is {service}")
}

let a = 1
let b = 2
a, b = b, a
say(a, b)

let more = [...ports, 3389]
let merged = {...host, "owner": "Tanisha"}
say(more)
say(merged)

22.More about functions: defaults, names, extras and lambdas

Inputs can have defaults, and you can pass any input by name. ...rest collects any extra inputs into a list, and **opts collects extra named ones into a map. A lambda such as x => x * 2 is a short way to write a small function.

fn connect(host, port = 22, timeout = 5) {
  return f"{host}:{port} (wait {timeout}s)"
}
say(connect("192.0.2.10"))
say(connect("192.0.2.10", 443))
say(connect("192.0.2.10", timeout = 1))

fn total(first, ...rest) {
  return first + rest.sum()
}
say(total(1, 2, 3, 4))

fn tag(text, **opts) {
  return f"{text} {opts}"
}
say(tag("alert", level = "high", owner = "Tanisha"))

let double = x => x * 2
let add = (a, b) => a + b
say(double(21), add(2, 3))
say([3, 1, 2].map(x => x * 10))
say([5, 12, 8].filter(n => n > 6))
say(double.name, add.arity)

say(add(...[10, 20]))

23.Values that never change: const

const is like let, but the name can never point at something else. (A list made with const can still grow; it's the name that is fixed.)

const MAX_TRIES = 5
const PORTS = [22, 80, 443]
say(MAX_TRIES, PORTS)
PORTS.push(8080)
say(PORTS)

Trying to change it is a mistake TB catches:

const MAX_TRIES = 5
MAX_TRIES = 6

24.Numbers in depth: whole numbers, bits and formats

Whole numbers can be as big as you like and can be written in hex (0xff), binary (0b1010) or octal (0o17), with _ to make them readable. / always divides exactly; // divides and rounds down. The bit operators & | ^ ~ << >> work on whole numbers, and comparisons can be chained.

After a : inside an f-string hole comes a format: .2f for two decimals, , for thousands, x for hex, b for binary, % for percent, and < > ^ with a width to line things up.

say(1_000_000, 0xff, 0b1010, 0o17, 2.5e-3)
say(7 / 2, 6 / 3, 7 // 2, -7 % 3, 2 ** 10)
say((7 / 2).is_float(), (6 // 3).is_int(), int(3.9), float(2))
say(0b1100 & 0b1010, 0b1100 | 0b1010, 0b1100 ^ 0b1010, ~0, 1 << 4, 256 >> 2)
let x = 5
say(0 < x <= 10)

let price = 1234.5678
say(f"{price:.2f} | {price:,.1f} | {255:x} | {255:08b} | {0.257:.1%}")
say(f"[{"left":<8}] [{"right":>8}] [{"mid":^8}] [{42:05}]")
say(format(3.14159, ".3f"), (1234567).format(","))

25.More about text: escapes, raw and multi-line

Escapes start with a backslash: \t is a tab, \xNN and \u{HEX} give any character. Raw text, r"...", keeps backslashes as they are, which is handy for Windows paths and regular expressions. Three quote marks make text that spans several lines, and text can be indexed and sliced like a list.

say("tab:\tend", "quote: \"", 'single: \'')
say("A is \x41, a heart is \u{2665}")
say(r"C:\Users\Tanisha\new")
let poem = """Roses are red,
logs can be read."""
say(poem)
let name = "Tanisha"
say(f"""Hello, {name}!
You have {3 + 4} alerts.""")
let s = "detection"
say(s[0], s[-1], s[0:6], s[::-1])

26.Bytes: the raw data inside files

Files and network packets are made of bytes, numbers from 0 to 255. b"..." writes bytes directly; text.bytes() and data.to_text() convert. The binary library packs and unpacks numbers the way file formats store them.

import binary
import hash

let data = b"MZ\x90\x00hello"
say(type(data), len(data), data.hex())
say(data[0], data.slice(0, 2), data.starts_with(b"MZ"))
for byte in data.slice(0, 4) {
  say(byte)
}
say("café".bytes(), b"caf\xc3\xa9".to_text())
let packed = binary.pack("<HI", 1, 70000)
say(packed.hex(), binary.unpack("<HI", packed))
say(hash.sha256(b"hello").slice(0, 16))

27.Ranges and slices

1..5 is a range from 1 up to (not including) 5, and 1..=5 includes the 5. Ranges are lazy: they don't build a list until you ask. Slices like xs[1:3] cut a piece out of a list, text or bytes; a third number is the step, so xs[::-1] is reversed.

let r = 1..5
say(r, r.to_list(), (1..=5).to_list(), len(r))
say(3 in r, 5 in r)
say((0..10).step(3).to_list())
for i in 0..3 {
  say("turn", i)
}
let xs = [10, 20, 30, 40, 50]
say(xs[1:3], xs[:2], xs[-2:], xs[::2], xs[::-1])

28.Choosing a value: if ... then ... else

When you just need to pick one of two values, if can be written on one line with then. It gives back the value of the branch it picked.

let tries = 7
let level = if tries > 5 then "high" else "low"
say(level)
for n in [1, 2, 3] {
  say(f"{n} is " + (if n % 2 == 0 then "even" else "odd"))
}

29.Kinds of errors, and finally

Every error is an Error object with a message, a line and a kind. Libraries throw specific kinds, such as ParseError or NotFoundError (a kind of FileError), and catch err: Kind catches only that kind. finally runs whatever happened. Make your own kinds by extending Error.

import json
import fs

try {
  json.parse("{not json")
} catch err: ParseError {
  say("bad JSON:", err.kind)
} finally {
  say("done reading")
}

try {
  fs.read("no-such-file.txt")
} catch err: NotFoundError {
  say("missing:", err.kind, err is FileError)
}

class QuotaError extends Error { }

fn spend(amount) {
  if amount > 100 {
    throw QuotaError("Too much at once", {"limit": 100})
  }
  return amount
}

try {
  spend(500)
} catch err: QuotaError or ValueError {
  say(err.message, err.limit, err.kind, err.line)
}

30.Generators: one value at a time

A function that uses yield becomes a generator: each time someone asks for the next value, it runs until the next yield and pauses there. That means it can describe an endless sequence, and only the values you take are ever made. .next() gives done when it has finished.

fn countdown(n) {
  while n > 0 {
    yield n
    n -= 1
  }
}
for x in countdown(3) {
  say(x)
}

fn evens() {
  let n = 0
  while true {
    yield n
    n += 2
  }
}
say(evens().take(5).to_list())
say(evens().map(x => x * x).filter(x => x > 10).take(3).to_list())

let g = countdown(2)
say(g.next(), g.next(), g.next())
for i, word in ["a", "b"].enumerate() {
  say(i, word)
}

31.Doing things at the same time: async and await

Calling an async fn starts it as a task and gives you the task straight away; await waits for its answer. On your computer each task runs on its own thread, so slow work such as network checks overlaps. In the playground, tasks run one after another.

async fn check(host) {
  return f"{host} looks fine"
}

let tasks = ["web01", "web02", "db01"].map(h => check(h))
for t in tasks {
  say(await t)
}
say(type(tasks[0]))

The parallel library runs a function over many items at once. This one needs the TB app on your computer:

import net
import parallel

let hosts = ["192.0.2.10", "192.0.2.11", "192.0.2.12"]
let results = parallel.map(h => net.tcp_check(h, 443, 2), hosts, 8)
for [host, ok] in hosts.zip(results) {
  say(host, if ok then "open" else "closed")
}

32.Sharing code: export, from-import and packages

Any .tb file is a module. Mark what other files may use with export; everything else stays private:

# helpers.tb
export fn shout(text) { return text.upper() + "!" }
export const GREETING = "Hello"
fn secret() { return 42 }       # not exported
# main.tb
import "helpers.tb"
from "helpers.tb" import shout, GREETING as hi
say(shout(hi))

from ... import also works with the standard library, and as gives a name of your choice:

from json import parse, stringify
from text import pad_left as pad

let data = parse("{\"host\": \"web01\", \"alerts\": 3}")
say(stringify(data))
say(pad("7", 3, "0"))

Packages are modules other people wrote. tb add tb-tables installs one into your project, then import "tb-tables" as tables. See Packages.

33.assert and defer

assert checks something you believe is true and stops with an AssertionError if it isn't. defer { ... } inside a function runs when the function finishes, however it finishes: the right place to close files or print a summary.

fn work() {
  defer { say("cleaning up (runs last)") }
  say("working")
  return "result"
}
say(work())

let ports = [22, 443]
assert len(ports) == 2, "expected two ports"
try {
  assert 1 + 1 == 3, "maths is broken"
} catch err: AssertionError {
  say("caught:", err.message)
}

Reference: built-in instructions

These eight instructions have been in TB from the start. Version 2.0 adds a few more (type, keys, int, round, min, max, sum, sorted, exit), plus methods on every value and 43 libraries (3.0 adds format, float and more): see the library reference.

say(value, ...)

returns nil

Shows values on the screen, with a space between each one. say() on its own prints an empty line.

say("Hi", 2)
say()
say([1, 2, 3])

len(list_or_text)

returns number

How many things are in a list, or how many letters are in some text.

say(len("TB"))
say(len([1, 2, 3]))

str(value)

returns text

Turns any value into text, so you can join it to other text.

say(str(5) + " cats")

num(text)

returns number

Turns text like "12" or "2.5" into a number. Says "Oops!" if the text isn't a number.

say(num("12") + 1)
say(num("2.5") * 2)

range(n) / (a, b) / (a, b, step)

returns list

Makes a list of whole numbers: from 0 (or a) up to, but not including, n (or b), going up by step.

say(range(3))
say(range(1, 4))
say(range(10, 0, -5))

push(list, value)

returns the list

Adds a value to the end of a list, and gives the same list back.

let snacks = ["cake"]
push(snacks, "mango")
say(snacks)

ask(question)

returns text

Shows the question, waits for an answer, and gives it back as text. Use num() to do maths with it.

let name = ask("What's your name? ")
say("Hello, " + name + "!")

care() / (name)

returns nil

Prints ♥ and a kind message, chosen at random. Give it a name to make it personal.

care()
care("Tanisha")

Little reminders

  • Text goes in quotes: "hello" or 'hello'.
  • let makes a new box; = on its own changes an existing one.
  • = puts a value in a box; == checks if two things are the same.
  • Lists count from 0.
  • Blocks of lines (for if, while, for, fn) go inside { }.
  • You don't need semicolons at the end of lines.
  • # starts a note that TB ignores.

Running a .tb file on your Windows laptop

The Playground works right here in your browser. To run TB programs on your laptop, without the internet:

  1. Get the installer, tb-windows-x64-setup.exe, from the Download page and run it.
  2. Write your program in Notepad and save it with a name ending in .tb, like hello.tb. (In the save box, choose "All files" so Notepad doesn't add .txt.)
  3. Double-click your .tb file, and a window opens to run it. Right-click it and choose Edit to change it.

The Download page has the full step-by-step guide, including what to click if Windows asks whether it's safe.
