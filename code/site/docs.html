Learn TB

A program is just a list of instructions for the computer, written down one after another. TB is a small, friendly language for writing those instructions. You don't need to know anything about programming to start. Go one lesson at a time, and press Run on any grey box to see it work.

You can change the code in the Playground as much as you like. Nothing you type can break your computer, and if something goes wrong TB just says "Oops!" and explains what it didn't understand.

1. Your first program: say

say shows something on the screen. Put what you want to show inside the round brackets, and put words inside quote marks "like this" so TB knows they are text.

say("Hello, Tanisha!")
say("This is my first program.")

TB reads your program from top to bottom, one line at a time. Each line here is one instruction.

You can give say several things at once, separated by commas. It puts a space between them. say("") with nothing in the quotes prints an empty line, which is nice for spacing things out.

say("I have", 2, "cats")
say("")
say("The end!")

Lines that start with # are comments: little notes for people. TB skips them completely.

# This line is a note. TB ignores it.
say("Only this line does something.")

2. Values: numbers, text, true and false

Everything a program works with is a value. TB has a few kinds:

  • Numbers, like 7, -3 or 2.5.
  • Text, inside double or single quotes: "hello" or 'hello'.
  • true and false, for yes and no.
  • nil, which means "nothing here".
  • Lists of other values, like [1, 2, 3] (more in lesson 5).
say(42)
say("forty-two")
say(true)
say(nil)
say([1, 2, 3])

To put a quote mark inside text, put a backslash in front of it: \". \n starts a new line inside the text.

say("She said \"hi\" to me.")
say("line one\nline two")

3. Remembering things with let

let gives a value a name, so you can use it again later. Think of it as a labelled box.

let name = "Tanisha"
let age = 25
say(name)
say(age)

To change what's in the box later, use the name and = without let. (let is only for making a new box.)

let mood = "sleepy"
say("This morning I felt " + mood)
mood = "happy"
say("After coffee I felt " + mood)

Names can use letters, numbers and _, but can't start with a number: favourite_food, day2. Capital letters matter: Name and name are different boxes.

4. Maths and joining text

TB can do sums. * means times and / means divide. % gives the remainder after dividing (so 7 % 2 is 1). Brackets work like in school maths.

say(2 + 3)
say(10 - 4)
say(6 * 7)
say(7 / 2)
say(7 % 2)
say((2 + 3) * 4)

+ also joins text together. If either side is text, TB joins them as text.

let first = "Tanisha"
let last = "Brahma"
say(first + " " + last)
say("I have " + 3 + " plants")

Text times a number repeats the text:

say("ha" * 3)
say("<3 " * 5)

Two helpers turn things into other things:

  • str(x) turns anything into text: str(5) is "5".
  • num(text) turns text like "12" into the number 12, so you can do maths with it.
let cups = num("2") + 1
say("Cups of tea today: " + str(cups))

5. Lists

A list keeps several values in order, inside square brackets, separated by commas.

let snacks = ["chocolate", "mango", "chips"]
say(snacks)
say(len(snacks))

len tells you how many things are in a list (or how many letters are in some text).

To get one thing out, put its position in square brackets. Careful: positions start at 0, so the first thing is at position 0, the second at 1, and so on. A negative position counts from the end.

let snacks = ["chocolate", "mango", "chips"]
say(snacks[0])
say(snacks[1])
say(snacks[-1])

You can swap one thing for another, and add new things to the end with push:

let snacks = ["chocolate", "mango", "chips"]
snacks[2] = "popcorn"
push(snacks, "ice cream")
say(snacks)

Two lists can be joined with +: [1, 2] + [3] is [1, 2, 3].

6. Making choices with if and else

if runs some lines only when something is true. The lines that belong to it go inside curly brackets { }. else says what to do otherwise.

let hour = 22
if hour >= 22 {
  say("Time for bed. Sleep well!")
} else {
  say("Still time to play.")
}

You can check several things in a row with else if. TB uses the first one that is true.

let cups_of_water = 3
if cups_of_water >= 8 {
  say("Amazing, so hydrated!")
} else if cups_of_water >= 4 {
  say("Good going, keep sipping.")
} else {
  say("Maybe have a glass of water now?")
}

Ways to compare things:

  • == is the same as (two equals signs, because one = is for putting things in boxes)
  • != is not the same as
  • < less than, > more than, <= less than or the same, >= more than or the same

Join checks together with and and or, and flip one with not.

let sunny = true
let weekend = false
if sunny and not weekend {
  say("Sunny, but it's a work day.")
}
if sunny or weekend {
  say("Something nice is happening!")
}

In TB only false and nil count as "no". Everything else, even 0 and empty text "", counts as "yes".

7. Doing things again and again: loops

while keeps repeating its lines as long as something is true. Make sure something changes each time, or it will go on forever!

let n = 3
while n > 0 {
  say(str(n) + "...")
  n = n - 1
}
say("Surprise!")

for goes through a list one thing at a time. Each time round, the name you choose (here flower) holds the next thing.

let flowers = ["rose", "tulip", "sunflower"]
for flower in flowers {
  say("I picked a " + flower)
}

range makes a list of numbers to count with. range(5) is [0, 1, 2, 3, 4] (it stops just before 5). range(1, 4) is [1, 2, 3]. A third number sets the step: range(10, 0, -5) is [10, 5].

for i in range(1, 4) {
  say("Hug number " + str(i))
}

for also works on text, one letter at a time:

for letter in "TB" {
  say(letter)
}

8. Making your own instructions: functions

A function is a little recipe with a name. You write it once with fn, then use it as many times as you like. The names in the round brackets are its inputs.

fn greet(name) {
  say("Hello, " + name + "! You look lovely today.")
}

greet("Tanisha")
greet("Mum")

return hands a value back, so you can use the answer somewhere else.

fn double(x) {
  return x * 2
}

say(double(4))
say(double(double(4)))

Write a function above the place where you use it, because TB reads from top to bottom. A function with no return gives back nil.

9. Functions that remember (and call themselves)

A function can be a value too: fn(x) { ... } without a name makes one, and you can keep it in a box with let.

let shout = fn(text) {
  return text + "!!!"
}
say(shout("I love you"))

Here is something magical: a function made inside another function remembers the boxes around it, even after the outer function has finished. This is called a closure. Each counter below has its very own memory.

fn make_counter() {
  let count = 0
  return fn() {
    count = count + 1
    return count
  }
}

let hugs = make_counter()
hugs()
hugs()
say("Hugs so far: " + str(hugs()))

A function can also call itself, with a smaller problem each time. This is called recursion. Just make sure there's a point where it stops!

fn hearts(n) {
  if n <= 0 {
    return ""
  }
  return "<3 " + hearts(n - 1)
}
say(hearts(4))

10. Talking to your program: ask and care

ask shows a question and waits for you to type an answer and press Enter. The answer comes back as text. (In the browser, the question pops up in a little box.)

let name = ask("What's your name? ")
say("Nice to meet you, " + name + "!")

The answer is always text, so if you want to do maths with it, turn it into a number with num:

let cups = num(ask("How many cups of tea today? "))
say("Only " + str(cups + 1) + " more and you'll be a professional.")

care is TB's special instruction. It prints a little heart and a kind message, picked at random. Give it a name to make the message personal.

care()
care("Tanisha")

Try the Care bot example to see ask and care working together.

11. Reading "Oops!" messages

Everyone who writes programs makes little mistakes all the time. It's completely normal! When TB can't understand something, it stops and tells you which line to look at and what confused it:

Oops! On line 2: I don't know what 'nmae' is. Did you mean 'name'?

Try running this one. It has a typo on line 2:

let name = "Tanisha"
say(nmae)

Some common "Oops!" messages and what they mean:

  • I don't know what 'x' is. You used a name that hasn't been made yet, or there's a spelling mistake. Check the spelling, or add a let.
  • 'x' doesn't exist yet. Use 'let x = ...' first. You tried to change a box before making it. Use let the first time.
  • This text never ends. Did you forget a closing "? A quote mark is missing.
  • ... was never closed. Did you forget a ')'? (or a }) Every opening bracket needs a closing one.
  • Position 3 is outside the list. Remember positions start at 0, so a list of 3 things has positions 0, 1 and 2.
  • I can only subtract numbers ... You tried to do maths with text. Use num() to turn the text into a number first.
# This one has a mistake too. Can you fix it?
let snacks = ["cake", "chips", "mango"]
say(snacks[3])

Tip: the line number is your best friend. Go to that line, read it slowly, and look for a missing quote, bracket or spelling mistake. Sometimes the real mistake is on the line just above.

Built-in instructions (quick reference)

These come with TB, ready to use.

InstructionWhat it doesExample
say(a, b, ...) Shows things on the screen, with a space between each one. say() on its own prints an empty line. say("Hi", 2) shows Hi 2
len(x) How many things are in a list, or how many letters are in some text. len("TB") is 2
str(x) Turns any value into text. str(5) + " cats" is "5 cats"
num(text) Turns text like "12" or "2.5" into a number. Says "Oops!" if the text isn't a number. num("12") + 1 is 13
range(n)
range(a, b)
range(a, b, step)		 Makes a list of whole numbers: from 0 (or a) up to, but not including, n (or b), going up by step. range(3) is [0, 1, 2]
push(list, value) Adds a value to the end of a list. push(snacks, "cake")
ask(question) Shows the question, waits for an answer, and gives it back as text. let name = ask("Name? ")
care()
care(name)		 Prints ♥ and a random kind message, made personal if you give a name. care("Tanisha")

Little reminders

  • Text goes in quotes: "hello" or 'hello'.
  • let makes a new box; = on its own changes an existing one.
  • = puts a value in a box; == checks if two things are the same.
  • Lists count from 0.
  • Blocks of lines (for if, while, for, fn) go inside { }.
  • You don't need semicolons at the end of lines.
  • # starts a note that TB ignores.

Running a .tb file on your Windows laptop

The Playground works right here in your browser. To run TB programs on your laptop, without the internet:

  1. Get tb-windows-x64.exe from the Download page.
  2. Write your program in Notepad and save it with a name ending in .tb, like hello.tb. (In the save box, choose "All files" so Notepad doesn't add .txt.)
  3. Drag your .tb file onto the TB program, and a window opens to run it.

The Download page has the full step-by-step guide, including what to click if Windows asks whether it's safe.
